# Changelog

## 1.1.0 — 2026-11-04

Новая версия ASM Sentinel с расширенным управлением сканированиями.

### Добавлено

- Выбор модулей при запуске скана: `nmap`, проверка слабых паролей (bruter),
  `nuclei`, `ZAP`.
- Проверка слабых паролей SMB / SSH / MSSQL / PostgreSQL по словарям.
  Найденные учётные данные сохраняются как уязвимость `critical` с логином,
  паролем и местом обнаружения.
- Вкладка **«Конфигурация»** с редактируемыми словарями логинов, паролей и баз
  данных. Brute-модуль читает словари из БД.
- Поле **«Порты nmap»**: конкретные порты и диапазоны, например `22,445` или
  `22,445,8000-8100`.
- Параметры сканирования сгруппированы по сканерам.
- Раздел **«Регулярные сканирования»**: интервал, следующий запуск, модули,
  порты, ZAP/nuclei; редактирование и удаление.
- Офлайн-установка: `vendor/wheels` (Linux x86_64 / CPython 3.12),
  `install-offline.sh` и инструкция `docs/OFFLINE.md`.

### Изменено

- При добавлении цели сканирование больше не запускается сразу.
- Регулярность перенесена из карточки цели в раздел «Сканирования».
- Одноразовый скан не меняет настройки цели — параметры хранятся в самом скане.
- Старые цели с включённым расписанием одноразово переносятся в регулярные
  сканирования.

### Исправлено

- SSH brute: retry/backoff при banner/timeout и остановка после первого
  успешного логина.
- Валидация списка портов перед передачей в nmap.

### Следующая версия (бэклог)

- Объединить «Новое сканирование» и «Регулярное» в одну форму: галочка
  «Регулярное» раскрывает поля расписания.
